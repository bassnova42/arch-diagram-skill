# RokoAI arch-diagram · Skill วาดแผนภาพสถาปัตยกรรม

ใช้ได้กับ **Claude Code** และ **Codex**

ส่ง GitHub repository บทความเทคนิค ไฟล์ PDF หรือโปรเจกต์ในเครื่องให้ แล้ว Claude Code หรือ Codex จะอ่านโครงสร้างและวาดแผนภาพสถาปัตยกรรม ค่าเริ่มต้นเป็นโทนมืดสไตล์ "พิมพ์เขียวเทอร์มินัล" และเลือกได้อีก 7 สไตล์ (ดู [สไตล์](#สไตล์)) มีแพ็กเก็ตวิ่งไปตามเส้นเชื่อม และ log ด้านล่างจะเพิ่มบรรทัดใหม่แบบเรียลไทม์ทุกครั้งที่โมดูลส่งข้อมูลถึงกัน

**ด้านล่างคือแผนภาพสถาปัตยกรรมของโปรเจกต์โอเพนซอร์ส [morluto/rea](https://github.com/morluto/rea) ที่ Skill นี้สร้างขึ้นอัตโนมัติจาก GitHub repository:**

![แผนภาพสถาปัตยกรรมของ morluto/rea](examples/rea.gif)

ตัวอย่างเพิ่มเติม (บทความ, GitHub repository, เอกสารความต้องการ) ดูได้ที่ [ตัวอย่าง](#ตัวอย่าง) ท้ายหน้า

## ทำอะไรได้บ้าง

- **เลือกโครงสร้างตามเนื้อหา**: ระบบแบบเลเยอร์ ไปป์ไลน์ กระบวนการที่มีลูป แบบศูนย์กลาง-ซี่ล้อ สวิมเลน หรือแผนผังลำดับชั้น ไม่ใช้เทมเพลตตายตัว
- **สีที่มีความหมาย**: กล่องใช้สีตามประเภท เส้นเชื่อมแยกสีและเส้นทึบ/เส้นประตามชนิดของการไหล (คำขอ การเขียน การตอบกลับ แบบอะซิงก์ ฯลฯ) กรอบกลุ่มแสดงความสัมพันธ์แบบอยู่ภายใน
- **live trace log**: เมื่อแพ็กเก็ตไปถึงปลายเส้น จะเพิ่มบรรทัด `เวลา · ประเภท · A → B · รายละเอียด` ที่ด้านล่าง
- **ตรวจสอบตัวเอง**: ใช้ Chrome แบบ headless ตรวจหากล่องซ้อนกัน ข้อความล้น เส้นที่ทะลุกล่อง และป้ายที่ถูกบัง แล้ว Claude จะแก้จนเลย์เอาต์เรียบร้อย
- **8 สไตล์**: เทอร์มินัลยามค่ำ พิมพ์เขียว กระดาษเขียนแบบ ไวต์บอร์ดวาดมือ บรูทัลจัดจ้าน CRT เรืองแสง การ์ดนุ่ม และกระบะทรายไอโซ เปลี่ยนได้ด้วยประโยคเดียว
- **ส่งออกได้หลายรูปแบบ**:
  - HTML ไฟล์เดียวแบบโต้ตอบได้
  - PNG (ความละเอียด 2 เท่า)
  - MP4: ค่าเริ่มต้น 20 วินาที กำหนดความยาวได้ตามต้องการ วนซ้ำทุก 4 วินาทีอย่างไร้รอยต่อ
  - GIF: หนึ่งรอบ
  - ผังงาน Mermaid

## ภาษาของแผนภาพเป็นไปตามภาษาของพรอมต์

แผนภาพจะเขียนด้วยภาษาเดียวกับที่คุณใช้สั่ง:

- เขียนพรอมต์เป็น**ภาษาไทย** แผนภาพทั้งหมดจะเป็นภาษาไทย
- เขียนเป็น**ภาษาอังกฤษ** ก็จะได้ภาษาอังกฤษ
- เขียนเป็น**ภาษาจีน** หัวข้อ คำอธิบาย ป้ายกำกับ และ log จะเป็นภาษาจีน
- เขียนเป็น**ภาษาญี่ปุ่น** เนื้อหาทั้งหมดจะเป็นภาษาญี่ปุ่น

แม้บทความหรือซอร์สโค้ดต้นฉบับจะเป็นภาษาอื่นก็ตาม ชื่อในโค้ด พาธ และคำสั่งจะคงไว้ตามเดิม ข้อความส่วนติดต่อ เช่น คำอธิบายสัญลักษณ์และป้ายสถานะ มีในตัวสำหรับภาษาจีน อังกฤษ ญี่ปุ่น เกาหลี สเปน และไทย ส่วนภาษาอื่น Claude จะเขียนเป็นภาษานั้นให้

## การติดตั้ง

ต้องมี Node 18 ขึ้นไป และ Chrome, Chromium หรือ Edge การส่งออกวิดีโอและ GIF ต้องมี `ffmpeg` ด้วย (`brew install ffmpeg`)

**วิธีที่ 1: npm** (ง่ายที่สุด)

```bash
npx @rokoai/arch-diagram install
```

จะติดตั้งไว้ที่ `~/.claude/skills/arch-diagram` ถ้าเติม `--project` จะติดตั้งใน `.claude/skills/` ของโปรเจกต์ปัจจุบัน รันอีกครั้งเพื่ออัปเดต และถอนการติดตั้งด้วย `npx @rokoai/arch-diagram uninstall`

ถ้าติดตั้ง Codex ไว้ (มีโฟลเดอร์ `~/.codex`) จะติดตั้งลง `~/.codex/skills/arch-diagram` ด้วย ถ้าต้องการติดตั้งให้ตัวใดตัวหนึ่งเท่านั้น ให้เติม `--claude` หรือ `--codex`

> ถ้ารัน `npx @rokoai/arch-diagram …` ภายในโฟลเดอร์ที่ clone repo นี้มา จะเจอ `arch-diagram: command not found` เพราะ npm มองโฟลเดอร์ปัจจุบันเป็นแพ็กเกจนี้เอง และไม่ได้เพิ่มคำสั่งลงใน PATH ให้รันจากโฟลเดอร์อื่น หรือใน clone ให้ใช้ `node bin/cli.mjs install` แทน (ใช้ตัวเลือกเดียวกัน เช่น `--codex`)

**วิธีที่ 2: ปลั๊กอิน** ใน Claude Code ให้รัน:

```
/plugin marketplace add bassnova42/arch-diagram-skill
/plugin install arch-diagram@arch-diagram
```

ใน Codex CLI:

```bash
codex plugin marketplace add bassnova42/arch-diagram-skill
codex plugin add arch-diagram@arch-diagram
```

**วิธีที่ 3: คัดลอกเอง**

```bash
git clone https://github.com/bassnova42/arch-diagram-skill
cp -R arch-diagram-skill/skills/arch-diagram ~/.claude/skills/
cp -R arch-diagram-skill/skills/arch-diagram ~/.codex/skills/   # Codex
```

รีสตาร์ต Claude Code หรือ Codex หลังติดตั้ง

## วิธีใช้

สั่งใน Claude Code หรือ Codex ได้เลย เช่น:

- `วาดแผนภาพสถาปัตยกรรมของ https://github.com/plausible/analytics`
- `ทำบทความนี้เป็นผังงาน: <URL> แล้วส่งออกเป็นวิดีโอ 30 วินาที`
- `ส่งออกแผนภาพเมื่อกี้เป็นรูปภาพ` / `เป็น mermaid`
- ถ้าต้องการเรียก Skill นี้โดยตรง: ใน Claude Code พิมพ์ `/arch-diagram <URL>` ใน Codex พิมพ์ `$arch-diagram <URL>`

ต้นฉบับของแต่ละแผนภาพคือ `<slug>.spec.json` ถ้าต้องการแก้ ให้บอก Claude Code หรือ Codex แก้ spec แล้วสร้างใหม่ หรือจะใช้บรรทัดคำสั่งโดยตรงก็ได้:

```bash
npx @rokoai/arch-diagram build  my.spec.json my.html
npx @rokoai/arch-diagram check  my.html
npx @rokoai/arch-diagram export my.html my.png my.mp4 --seconds 30
```

## สไตล์

สไตล์เริ่มต้นคือ **เทอร์มินัลยามค่ำ** (`terminal`) และยังมีอีก 7 สไตล์ แค่บอกสไตล์ในคำขอ เช่น `วาดแบบพิมพ์เขียว` `ใช้สไตล์ไวต์บอร์ดวาดมือ` `ทำเป็น 3D แบบไอโซเมตริก` ถ้าไม่ระบุจะใช้สไตล์เริ่มต้น

- **เปลี่ยนแค่หน้าตา**: spec เดียวกันวาดได้ทุกสไตล์ การเปลี่ยนสไตล์ไม่แตะโครงสร้าง ข้อความ หรือพิกัด และการตรวจตัวเองก็เหมือนเดิม แผนภาพที่มีอยู่แล้วก็วาดใหม่ได้ด้วยประโยคเดียว เช่น "เปลี่ยนเป็นสไตล์การ์ดนุ่ม"
- **ความหมายของสีไม่เปลี่ยน**: แต่ละสไตล์มีชุดสีของตัวเอง แต่น้ำเงิน ฟ้าอมเขียว เขียว อำพัน และม่วง ยังหมายถึงองค์ประกอบประเภทเดิม จึงอ่านคำอธิบายสัญลักษณ์ได้เหมือนเดิม
- **ส่งออกได้ทุกรูปแบบ**: HTML, PNG, MP4 และ GIF ส่งออกได้ทุกสไตล์ (Mermaid จัดวางเองจึงไม่มีสไตล์)

### พิมพ์เขียว · `blueprint`

![พิมพ์เขียว](themes/blueprint.gif)

- **หน้าตา**: หมึกขาวบนพื้นน้ำเงินพิมพ์เขียว มีตาราง 20px / 100px และกรอบเส้นคู่ มุมกล่องมีเครื่องหมายกากบาท ป้ายเส้นเป็นตัวเอียง เส้นอะซิงก์เป็นเส้นประยาว สีเปลี่ยนเป็นโทนอ่อนเพื่อให้ยังแยกออกบนพื้นน้ำเงิน
- **เหมาะกับ**: รีวิวการออกแบบระบบ เอกสารข้อเสนอทางเทคนิค หรืองานที่อยากให้ดูเป็นแบบวิศวกรรม
- **วิธีขอ**: `วาดแบบพิมพ์เขียว` · `สไตล์ blueprint`

### กระดาษเขียนแบบ · `drafting`

![กระดาษเขียนแบบ](themes/drafting.gif)

- **หน้าตา**: หมึกบนกระดาษเขียนแบบสีครีมมีลายกระดาษ ตัวอักษรมีเชิง และกรอบเส้นคู่ ทุกองค์ประกอบมีวงกลมหมายเลขที่มุมซ้ายบนเพื่ออธิบายทีละข้อ เส้นเริ่มด้วยจุด และเส้นอะซิงก์เป็นเส้นประสลับจุด
- **เหมาะกับ**: งานพิมพ์ ส่งออก PDF ภาพในคู่มือหรือบทความ หรือการอธิบายตามหมายเลข
- **วิธีขอ**: `สไตล์เขียนแบบ` · `แบบคู่มือเทคนิค`

[▶ วิดีโอ 20 วินาที (MP4)](themes/drafting.mp4)

### ไวต์บอร์ดวาดมือ · `whiteboard`

![ไวต์บอร์ดวาดมือ](themes/whiteboard.gif)

- **หน้าตา**: ปากกาเมจิกบนไวต์บอร์ด เส้นสั่นเล็กน้อย กล่องระบายสีด้วยเส้นทแยง หัวลูกศรแบบเปิด และไฮไลต์ใต้ชื่อเรื่อง การสั่นใช้ seed คงที่ ทุกครั้งจึงได้ภาพเหมือนเดิมและวิดีโอยังวนต่อได้ไม่มีรอยต่อ
- **เหมาะกับ**: ระดมความคิด คุยแบบร่างช่วงแรก อธิบายให้คนที่ไม่ใช่วิศวกร ภาพประกอบบล็อก
- **วิธีขอ**: `สไตล์วาดมือ` · `แบบไวต์บอร์ด` · `วาดเป็นสเก็ตช์`
- **หมายเหตุ**: ถ้าติดตั้งฟอนต์ลายมือไว้จะดูเหมือนเขียนมือมากขึ้น ถ้าไม่มีจะใช้ฟอนต์ของระบบ ส่วนเส้นยังเป็นแบบวาดมือเหมือนเดิม

### บรูทัลจัดจ้าน · `brutalism`

![บรูทัลจัดจ้าน](themes/brutalism.gif)

- **เหมาะกับ**: ภาพหลักของ README โซเชียลมีเดีย สไลด์ และโปสเตอร์ ที่ต้องดึงสายตาตั้งแต่แรกเห็น
- **วิธีขอ**: `สไตล์บรูทัลลิสม์` · `ให้เด่นขึ้น` · `แบบโปสเตอร์`

### CRT เรืองแสง · `crt`

![CRT เรืองแสง](themes/crt.gif)

- **หน้าตา**: จอหลอดภาพสีดำอมเขียว ตัวอักษรและเส้นเรืองแสงแบบฟอสฟอร์ กล่องเป็นเส้นคู่ มีเส้นสแกนและขอบมืดทั่วหน้า และมีพรอมต์ `>` หน้าชื่อเรื่อง
- **เหมาะกับ**: หัวข้อความปลอดภัย วิศวกรรมย้อนกลับ และโครงสร้างพื้นฐาน การบรรยายสไตล์เรโทร ภาพปกวิดีโอ
- **วิธีขอ**: `เทอร์มินัลย้อนยุค` · `สไตล์ CRT` · `เขียวเรืองแสง`

[▶ วิดีโอ 20 วินาที (MP4)](themes/crt.mp4)

### การ์ดนุ่ม · `saas`

![การ์ดนุ่ม](themes/saas.gif)

- **หน้าตา**: พื้นหลังสว่างลายจุด การ์ดสีขาวมุมมน มีแถบสีบาง ๆ ด้านบนและเงานุ่ม มุมเส้นโค้งมน ป้ายรูปแคปซูล และเส้นอะซิงก์เป็นจุด
- **เหมาะกับ**: เอกสารผลิตภัณฑ์ เว็บไซต์ การนำเสนอภายนอก และเว็บเอกสารโทนสว่าง (Notion, Confluence ฯลฯ)
- **วิธีขอ**: `สไตล์สว่างเรียบ` · `แบบเอกสารผลิตภัณฑ์` · `สไตล์ SaaS`

### กระบะทรายไอโซ · `isometric`

![กระบะทรายไอโซ](themes/isometric.gif)

- **หน้าตา**: แผนภาพที่จัดวางและตรวจตัวเองเสร็จแล้วจะถูกวางลงบนพื้นตารางไอโซเมตริก ทุกกล่องกลายเป็นบล็อกที่มีความหนาและเงา ส่วนหัว คำอธิบายสัญลักษณ์ และ log ยังตั้งตรง ผืนภาพจะกว้างขึ้นราว 1.5 เท่าแทนการย่อตัวอักษร
- **เหมาะกับ**: ภาพปก ภาพโปรโมต ภาพรวมของระบบที่มีองค์ประกอบไม่มาก
- **วิธีขอ**: `สไตล์ 3D` · `แบบไอโซเมตริก` · `ทำให้เป็นสามมิติ`
- **หมายเหตุ**: ตัวอักษรเอียงตามพื้นด้วย จึงเหมาะกับโหนดไม่เกินราว 12 ตัว ถ้าแผนภาพแน่นมากควรเลือกสไตล์อื่น

## โครงสร้างไดเรกทอรี

```
skills/arch-diagram/
  SKILL.md            ขั้นตอน: อ่านต้นทาง → เลือกโครงสร้าง → จัดวาง → ตรวจสอบ → ส่งออก
  assets/             เอนจินเรนเดอร์ สไตล์ เทมเพลต และ themes/ สำหรับไฟล์สไตล์ของแต่ละแบบ
  scripts/            build / check / export
  references/         คำอธิบายฟิลด์ spec สไตล์ภาพ
  examples/           rea (repository), plausible (repository), elephant-goldfish (บทความ)
bin/cli.mjs           คำสั่ง npm: install / uninstall / build / check / export
```
